1. Explain that the application is a synthetic simulation, not a live warehouse control system.
2. Launch the Streamlit dashboard using the instructions in the README.
3. Select Normal, Peak, and Extreme scenarios; compare the aisle congestion and worker movement view.
4. Toggle the wave-release controller and explain ALLOW / DELAY / BLOCK.
5. Demonstrate a telemetry tamper rejection and explain the MANUAL FALLBACK / store-and-forward behavior.
6. Show the baseline-versus-controlled experiment CSV and explain the cost, time, emissions, and reliability measures.
